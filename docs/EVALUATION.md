## Reproduce

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -c requirements-demo.lock -e '.[dev]'
python -m unittest discover -s tests -v
python -m quote_agent.demo
python -m quote_agent.demo --scenario shortage
python -m quote_agent.demo --scenario malformed-model
python -m pip check
```

`requirements-demo.lock` is the tested demo/dev dependency snapshot, used as constraints. It is not a hash-verified or universal platform lock. The initial clean install used isolated pip builds; constraint resolution was also rechecked after explicitly installing the setuptools/wheel build tools in the temporary environment. Installation needs network access; subsequent demos and tests do not. The SQL driver is an optional `cloud` extra and was not installed in the clean demo environment. Starlette currently emits a TestClient/httpx deprecation warning; the tests pass without suppressing it.

With optional historical data available, run:

```sh
python -m wwi_sqlite verify --output-dir data/sqlite
python tools/verify_portfolio_fixtures.py
```

Existing databases were verified, not rebuilt. Full historical fixture regeneration was not attempted; its Node artifact-tool prerequisite remains environment-specific.

## Important regression scenarios

| Scenario | Verified behavior |
|---|---|
| Missing customer or no lines | `needs_clarification`; aggregate totals withheld |
| Unknown explicit SKU or ambiguous description | No guessed substitution; clarification required |
| Model supplies a SKU absent from the source | ID hint cannot force a match |
| Zero, negative, string, boolean, infinite, NaN or omitted quantity | Schema rejection |
| Fractional normalized stock unit or missing conversion | Clarification; no invented unit rule |
| Insufficient stock, including repeated lines | Combined demand checked; no quote total |
| Negative/nonfinite price, invalid tax, wrong price unit/item identity or inconsistent repeated price | Ready quote blocked; manual review/error routing |
| Model adds financial fields | Strict draft schema rejects them |
| Model writes a low price or send instruction in suggested prose | Final figures and reply remain generated by Python |
| Forged agent price/stock research trace | Independent validation uses actual catalog and stock facts |
| Pricing agreement reference | Review required; discount never applied automatically |
| Failed/truncated attachment extraction | Incomplete-source flag blocks a ready quote |
| Malformed model JSON or model/network failure | Explicit error, no financial proposal totals |
| Unregistered write/SQL tool call | Tool allowlist rejects it; SQLite also rejects writes |
| Tool loop or malformed tool arguments | Bounded loop; invalid arguments recorded as tool errors |
| Failed deterministic lookup | Error outcome retains extracted draft and safe lookup-error trace |
| Graph/Teams failure | Adapter raises; Graph failure does not reach review publication |
| Malformed webhook/wrong clientState | Rejected; duplicate IDs within a batch processed once |
| Background integration failure | HTTP 202 acknowledged, failure logged; no retry guarantee |

## What was not evaluated

The replay uses authored model output. These tests do not measure live intent accuracy, extraction completeness, hallucination rate, confidence calibration, prompt-injection resistance, latency, cost, throughput, business savings or customer outcomes. Historical private runs are not a labeled evaluation dataset.

Live Microsoft authentication/consent, Graph subscription delivery and renewal, the SQL driver/network/schema, Teams Workflow compatibility and deployed hosting were not exercised. There is no proof of durable delivery, exactly-once processing, concurrent inventory safety or production readiness. PDF OCR, exhaustive attachment-format coverage and a hardened document sandbox are absent.

## Live OpenRouter observations

The same Cedar Workshop RFQ was submitted to the real configured DeepSeek Flash classifier and DeepSeek Pro handler on October 23, 2026 using the ignored local key file. The successful run `2543a0b637e7` used five model calls, ten read-only local tool calls and nine independent validation lookups. It returned `quote_ready`: subtotal $84.20, tax $6.32, total $90.52 before freight. The model extracted the original 2 Outer and 3 Each correctly; Python performed conversion, validation and arithmetic.

Two earlier attempts (`0452ac2823fa` and `92c90f2078f4`) omitted final line items and were blocked as `needs_clarification`, with no totals. The observed omissions led to separation of research/finalization and explicit required fields in the API schema. All attempts remain under ignored `runs/live-synthetic/`, with actual response messages, model IDs, usage and timing metadata. No email or Teams adapter was constructed, and only the OpenRouter completions endpoint was allowed by the runner.

A second completed live run, `8e63580a8f76`, processed the identical RFQ with dispenser inventory reduced to 2. The model retained the request for 3; Python returned `insufficient_stock` and withheld aggregate totals. This run also used five model calls, ten read-only tools and nine validator lookups. An initial upstream rate-limit failure was retained before retrying. [Synthetic audit snapshots](../examples/live-rfq/README.md) document both completed runs.

These two examples after protocol fixes are integration evidence, not a measure of extraction accuracy or reliability. This check does not change the unverified status of the Microsoft adapters. See [LIVE_DEMO.md](LIVE_DEMO.md) for the command and boundaries.
